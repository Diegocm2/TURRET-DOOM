# Turret Doom

Proyecto desarrollado como videojuego interactivo utilizando tecnologías web modernas.

## Descripción

Este proyecto consiste en un videojuego desarrollado utilizando React y JavaScript, diseñado como proyecto personal / universitario.

El objetivo principal del proyecto ha sido aplicar conocimientos de desarrollo frontend, gestión de componentes, lógica de programación y diseño de interfaces interactivas.

Actualmente el proyecto continúa en desarrollo y mejora continua.

---

## Tecnologías utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Electron
- Node.js

---

## Características

- Interfaz interactiva
- Sistema de lógica de juego
- Gestión de estados
- Ejecución como aplicación de escritorio mediante Electron

---

## Instalación

Clonar repositorio:

```bash
git clone https://github.com/Diegocm2/TURRET-DOOM
```

Entrar en la carpeta:

```bash
cd "TURRRET DOOM"
```

Instalar dependencias:

```bash
npm install
```

Ejecutar proyecto:

```bash
npm start
```

Para generar aplicación de escritorio:

```bash
npm run build
```
